# Compound Interest Calculator

This repository contains a simple and extensible script for calculating compound interest using Python. It's designed to help users understand how their investments grow over time with compound interest.

## Formula

A = P(1 + r/n)^(nt)

Where:
- A is the final amount
- P is the principal or initial investment
- r is the annual interest rate (as a decimal)
- n is the number of times interest is compounded per year
- t is the number of years

## Use Cases

- Educational tools for teaching interest and investment growth
- Financial calculators
- Personal budgeting and savings projections
